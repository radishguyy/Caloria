6.3b · Toast perubahan tersimpan
Perubahan tersimpan

Jadwal makan malam diubah menjadi 19:30. Pengingat berikutnya mengikuti waktu baru.

Toast muncul setiap toggle atau waktu berubah, lalu hilang otomatis setelah 2 detik.

6.3c · Izin browser ditolak
Web Push tidak dapat diaktifkan

Izin notifikasi diblokir browser. Buka pengaturan situs dan izinkan notifikasi untuk Caloria.

Toggle kembali ke posisi OFF. Pengingat dalam aplikasi tetap tersedia.

Cara mengaktifkan
  1. Anotasi & state
  2. Semua toggle dan input waktu auto-save. Toast “Perubahan tersimpan” muncul 2 detik, tanpa tombol simpan terpisah.
  3. Web Push default ON. Jika izin browser ditolak, toggle kembali OFF dan tampilkan panduan mengaktifkan izin.
  4. Jadwal makan default 08:00 / 12:30 / 19:00 WIB. Nilai harus berupa waktu valid dan dapat diubah per field.
  5. Poke Nudge default ON; evaluasi gizi & XP default OFF pada contoh ini agar terlihat kedua state toggle.
  6. Informasi akun memakai data sesi: Iman Nur, @iman_dev, iman@caloria.app. Email tidak bisa diedit dari halaman ini.
  7. Logout menghapus sesi dan mengarahkan ke /login. Tidak ada modal konfirmasi tambahan pada alur saat ini.
  8. Tombol “Kirim Notifikasi Uji” memakai izin Web Push yang sama; jika gagal, tampilkan error inline.
  9. Responsif: kolom pengaturan dan akun menumpuk; tiga input waktu menjadi satu kolom di bawah 560px.
  10. Halaman ini tidak menyimpan data sensitif baru dan tidak menampilkan fitur Plaza.
